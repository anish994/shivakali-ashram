## 🛠️ Development Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/anish994/shivakali-ashram.git
   cd shivakali-ashram
   ```

2. **Local development**
   - Open `index.html` in browser for basic testing
   - Use live server for development (VS Code Live Server extension)

3. **Future backend setup**
   ```bash
   cd api
   pip install -r requirements.txt
   python app.py
   ```
